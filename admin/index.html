Your data

Everything here is stored in this browser only — nothing is uploaded. Back up regularly: clearing your browsing data, or switching phone or laptop, will lose it otherwise.

Change the access key

Sets a new key for this device. To change it everywhere, set ADMIN_KEY in the host's environment variables (on Vercel: Project → Settings → Environment Variables) and redeploy — that keeps the key out of the public repo. A key saved here still wins on this device until you press “Back to the built-in key”.

Write the new key down before you save it. There is no way to recover it — if you forget it you'd have to clear this browser's site data, which deletes your enquiries too.
